Add optional experimental fountain transport with Cashu token conversion, binary
frame recovery, inbound UR decoding, and automatic format detection. Import the
nut-fountain 0.1.0-alpha.1's version-1 profile with up to 1024 source fragments and
an independent 1 MiB message limit, and align Cashu dependencies with Coco. Earlier
version-1 readers remain compatible with transfers of at most 256 fragments.
Version and publish fountain independently from the core package release group.
