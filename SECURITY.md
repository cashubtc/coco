# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to **cashu-security@pm.me**.

Do not open a public GitHub issue or disclose the vulnerability publicly until we have had a
reasonable opportunity to investigate and coordinate a fix.

Please include, where possible:

- The affected Coco package and version or commit
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept

Do not include real Cashu tokens, seed phrases, private keys, or other secrets.

We will acknowledge your report and coordinate remediation and disclosure with you.

## Coordinating a fix and disclosure

Security fixes are developed and disclosed in a coordinated way. Do not include
exploit details in public places: issues, pull requests (titles, bodies, review
comments), commit messages, or code comments. Keep public descriptions high-level
until a fix has been released and disclosure has been coordinated.

Until then, send the full report to the contact above, including impact, affected
versions, reproduction steps, a proof of concept if available, and a suggested fix.

## Supported Versions

Security fixes are provided for the latest released version.
